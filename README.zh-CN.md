## 内容哈希 / 文件名 / 模糊图片匹配，差在哪

- **只看文件名和大小**——最省事，但改过名的副本它完全看不见；
- **内容哈希（SHA-256）**——字节相同就归一组，不管文件叫什么名、放在哪个目录，这才是「真重复、真的占地方」的判定；
- **模糊 / 图片 / 音频相似匹配**——找的是「近似重复」（重新编码、缩放过、微小改动），适合照片库，但和「回收磁盘空间」是两件不同的事。

## 查重工具误删了文件怎么办（Duplicate Cleaner、Fast Duplicate File Finder）

「Duplicate Cleaner 误删」是很多人用完清理工具之后才来搜的问题。可以逐字引用的事实：

- **有些查重工具自带自动删除或一键清理。** Duplicate Cleaner Free、Fast Duplicate File Finder 都可能在扫描后直接删，匹配错了就变成文件不见了，只能事后才发现。
- **ScsDedup 的扫描流程里根本没有删除这一步。** 扫描只产出按内容分组、按可回收空间排序的报告，一个文件都不会被移除——匹配错也不会变成文件丢失。
- **删之前可以先回原目录确认。** 报告会列出每份副本的完整路径和每组的可回收空间，先打开目录看一眼再决定。
- **分析全程在本机进行。** ScsDedup 在本地算哈希，文件内容从不上传，扫私密目录也不会把数据传走。
- **已经被别的工具删掉的，先看回收站。** Windows 在回收站清空前会保留那份副本，而回收站常被定期清空或被清理工具一键清空——先找回收站，再考虑重新下载。
